# Changelog

All notable changes to LongView Markets are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.1.0/).

## [0.1.0] - 2026-05-30

### Added
- First WoW local product iteration with FastAPI backend and React TypeScript frontend.
- Deterministic demo seed data, SQLite metadata and Parquet analytical lake generation.
- Portfolio, simulated portfolio, dividend fisher, tax advisor, forecasting, data quality, screener, watchlists, journal, playbooks, learn, executive demo and external GPT copilot.
- Branded LongView Markets logo, favicon and packaging assets.
- Local launcher, Makefile, CI workflows, security checks, release workflow and documentation.
