# Screener

The screener ranks instruments by backend metrics and data quality. Presets cover dividends, momentum, drawdown, low volatility, defensive portfolio and high uncertainty.

## Operating Principle

Every financial page must expose source, date, data kind, confidence and limitations. Mock, simulation and forecast data are labeled separately from observed data.
