# Alerts

Alerts support portfolio, dividend, data quality, volatility and signal conditions. Each alert includes evidence, source, date, confidence and a prudent suggested action.

## Operating Principle

Every financial page must expose source, date, data kind, confidence and limitations. Mock, simulation and forecast data are labeled separately from observed data.
