# Forecasting

Forecasting uses simple baseline extrapolation and scenarios. Forecasts are marked as estimates and include limitations and confidence intervals.

## Operating Principle

Every financial page must expose source, date, data kind, confidence and limitations. Mock, simulation and forecast data are labeled separately from observed data.
