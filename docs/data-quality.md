# Data Quality

Quality checks detect non-positive prices, OHLC inconsistencies, duplicate dates, stale data and provider confidence. The frontend displays global and provider status.

## Operating Principle

Every financial page must expose source, date, data kind, confidence and limitations. Mock, simulation and forecast data are labeled separately from observed data.
