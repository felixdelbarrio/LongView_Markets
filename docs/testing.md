# Testing

Backend tests cover engines and API endpoints with an 80 percent coverage threshold. Frontend tests cover dashboard render, theme toggle and core pages. Playwright smoke tests validate navigation and favicon.

## Operating Principle

Every financial page must expose source, date, data kind, confidence and limitations. Mock, simulation and forecast data are labeled separately from observed data.
