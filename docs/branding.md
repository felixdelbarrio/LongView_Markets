# Branding

Brand assets live in `frontend/public/brand` and `scripts/package/assets`. The icon combines a long horizon, market line, data compass and an L mark. Packaging uses these assets and avoids generic Python icons.

## Operating Principle

Every financial page must expose source, date, data kind, confidence and limitations. Mock, simulation and forecast data are labeled separately from observed data.
