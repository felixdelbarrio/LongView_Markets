# Watchlists

Watchlists store tickers, reasons and follow-up actions. Demo lists cover dividends, quality technology, European defensive names and drawdown opportunities.

## Operating Principle

Every financial page must expose source, date, data kind, confidence and limitations. Mock, simulation and forecast data are labeled separately from observed data.
