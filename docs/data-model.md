# Data Model

Canonical entities are Instrument, DailyPrice, Dividend, NewsItem, PortfolioTransaction, Insight, Forecast, Watchlist and DecisionJournalEntry. Each relevant record carries source, date, confidence and data kind.

## Operating Principle

Every financial page must expose source, date, data kind, confidence and limitations. Mock, simulation and forecast data are labeled separately from observed data.
